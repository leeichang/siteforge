# SiteForge x Google Stitch 商業網站設計 Prompt

## Full business homepage

Paste this prompt into Google Stitch:

```text
Design a polished, production-ready business website homepage for a modern company. The website will be used as a template inside a website builder called SiteForge, so the layout must be modular, reusable, responsive, and easy to convert into editable sections.

Industry:
[replace with retail / beauty / beverage / consumer electronics / other]

Brand name:
[replace with brand name]

Business positioning:
[replace with one clear sentence describing what the company sells or provides]

Target audience:
[replace with primary customers, such as consumers, distributors, enterprise buyers, store visitors, members, or partners]

Design style:
Modern, trustworthy, commercial, elegant, and conversion-focused. Avoid a generic landing page. Avoid decorative-only sections. The page must feel like a real company website that can support sales, customer service, brand trust, and business inquiries.

Required homepage sections:
1. Header navigation
   - Logo
   - Main navigation: Home, About, Products, Services, News, Contact
   - Primary CTA button
   - Optional member/login or inquiry button

2. Hero section
   - Strong headline with the brand promise
   - Supporting description
   - Primary CTA
   - Secondary CTA
   - Product, service, store, or brand visual area
   - Trust indicators such as years in business, number of customers, stores, products, partners, or reviews

3. Product or service highlights
   - 3 to 6 cards
   - Each card must include title, short description, benefit, and CTA
   - Cards should be easy to reuse as SiteForge components

4. Brand value section
   - Explain why customers should trust this company
   - Include quality, service, professional experience, supply capability, support, or safety

5. Featured products or solutions
   - Product grid or solution grid
   - Include labels such as New, Popular, Recommended, Limited, or Business Plan
   - Include clear pricing, inquiry, or detail CTA where appropriate

6. Customer journey or service process
   - 3 to 4 steps
   - Example: Browse, Compare, Consult, Purchase, Support
   - Use icons and concise copy

7. Social proof
   - Testimonials, partner logos, press mentions, case results, customer counts, or store counts
   - Make it credible and not exaggerated

8. News, guides, or campaign section
   - 3 article cards
   - Include category, title, date, and short summary

9. Contact and conversion section
   - Inquiry form preview or CTA block
   - Include phone, email, business hours, location, social links, and partner inquiry

10. Footer
   - Company info
   - Quick links
   - Customer support
   - Policies
   - Social links
   - Copyright

Responsive requirements:
- Create both desktop and mobile versions.
- On mobile, the navigation should collapse into a clean menu.
- Text must never overlap with cards, images, buttons, or navigation.
- CTAs must remain visible and easy to tap.
- Product cards and service cards should stack cleanly.

Visual requirements:
- Use a professional color palette suitable for the chosen industry.
- Use real business website structure, not a marketing poster.
- Use consistent spacing, typography, icon style, button style, and card style.
- Keep cards with subtle borders or shadows, maximum 8px border radius.
- Avoid oversized empty hero sections.
- Avoid decorative gradient blobs or random abstract background shapes.
- Images should represent the actual product, store, service, or customer experience.

Output expectation:
Create a high-fidelity website homepage design with clear section hierarchy, realistic business copy, responsive layout, and reusable components suitable for implementation in SiteForge.
```

## Single page builder prompt

```text
Design a complete responsive website page for SiteForge.

Page type:
[Home / About / Products / Services / Contact / Blog / Case Study / Landing Page]

Industry:
[replace with industry]

Brand:
[replace with brand name]

Goal of this page:
[replace with the primary user action: inquiry, purchase, booking, membership signup, product comparison, store visit, or partner contact]

The page must include:
- Clear page title and intro
- Business-focused content sections
- Reusable cards or content blocks
- Strong CTA area
- Contact or next-step section
- Footer-compatible layout

Design it as a real company website page, not a generic landing page. Use polished spacing, readable typography, realistic content, clear hierarchy, and responsive desktop/mobile layouts.
```

## Reusable sections prompt

```text
Create a reusable section library for a website builder called SiteForge.

Industry:
[replace with industry]

Create the following reusable website sections:
1. Hero section
2. Product grid
3. Service cards
4. Feature comparison
5. Process steps
6. Testimonial section
7. Partner logos
8. News cards
9. Contact CTA
10. Footer

Each section should look like part of the same design system. Use consistent typography, spacing, buttons, cards, icons, and colors. The sections must be easy to convert into editable SiteForge blocks.

Create desktop and mobile variants.
```

## Industry replacements

Use these quick industry notes when filling the prompt.

### 零售業

- CTA: 探索商品、查找門市、加入會員、查看活動
- Sections: 熱門商品、門市據點、會員制度、促銷活動、顧客評價
- Visual: 商品陳列、門市、購物情境、會員優惠

### 美妝業

- CTA: 探索明星商品、開始肌膚測驗、預約諮詢、查看成分
- Sections: 明星商品、成分功效、膚質分類、使用教學、顧客評價
- Visual: 保養品、彩妝質地、肌膚情境、櫃點或沙龍

### 酒水業

- CTA: 探索產品系列、批發詢價、預約品飲、合作洽談
- Sections: 產品系列、風味介紹、搭餐建議、通路合作、活動體驗
- Visual: 酒瓶、飲品、餐桌、酒吧、品飲活動
- Reminder: Include responsible drinking message if alcoholic products are shown.

### 3C 產業

- CTA: 查看規格、立即購買、企業詢價、申請維修
- Sections: 熱門產品、規格比較、應用情境、技術優勢、保固支援
- Visual: 產品實拍、裝置使用情境、商用場景、支援中心
