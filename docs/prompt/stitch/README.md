# Google Stitch 網頁設計 Prompt

這個資料夾存放給 Google Stitch 使用的 SiteForge 網頁設計 prompt。

## 建議流程

1. 到 `https://stitch.withgoogle.com/`
2. 建立新設計
3. 貼上 [siteforge_business_website.md](./siteforge_business_website.md) 的 prompt
4. 依產業替換品牌、商品、服務與 CTA
5. 產出設計後，回到 SiteForge 將版面整理成：
   - 首頁模板
   - 產業頁面模板
   - 可重複使用的 hero、商品卡、服務卡、案例卡、聯絡表單區塊

## Stitch Prompt 使用建議

- 若要產生「完整網站首頁」，使用 `Full business homepage`。
- 若要產生「單一頁面」，使用 `Single page builder prompt`。
- 若要產生「可套用到 SiteForge 的元件庫」，使用 `Reusable sections prompt`。
- 產生後請要求 Stitch 同時提供 desktop 與 mobile layout。
