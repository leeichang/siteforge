# SiteForge 產業網站模板 Prompt

這個資料夾存放可直接貼到 SiteForge「AI 產生網站」功能的產業網站 prompt。

## 模板清單

- [零售業網站](./retail.md)
- [美妝業網站](./beauty.md)
- [酒水業網站](./beverage.md)
- [3C 產業網站](./consumer_electronics.md)

## 使用建議

建立網站時，建議搭配以下頁面類型：

- `home`
- `about`
- `services`
- `product`
- `contact`
- `blog`

如果是品牌形象或型錄網站，可以先用 `home/about/product/contact/blog`。如果是偏 B2B 或通路合作網站，建議加入 `services`，強化合作方案、供應能力與詢價轉換。
