# 零售業公司網站 Prompt

## SiteForge AI 產站 Prompt

請為一家「零售業公司」設計完整的商業網站。網站要看起來像成熟可信任的零售品牌官網，適合百貨、連鎖門市、生活選品、超市、便利商店、服飾零售或複合式零售品牌使用。

網站風格要現代、清楚、商業化、有品牌感，版面要重視商品展示、門市資訊、促銷活動、會員服務與顧客信任。整體視覺要乾淨、有秩序，避免過度花俏。請使用清楚的 CTA，引導使用者瀏覽商品、查找門市、加入會員、查看活動或聯絡合作。

## 必備網站內容

請產生一個完整公司網站，至少包含以下內容：

1. 首頁
   - 品牌名稱與一句明確定位，例如「讓日常採買更簡單、更有質感」
   - 主視覺 hero 區塊，包含品牌價值、主要 CTA、次要 CTA
   - 熱門商品或主打品類
   - 當季促銷或最新活動
   - 會員制度重點
   - 門市據點與線上購物入口
   - 顧客信任元素，例如服務年資、門市數、會員數、好評數

2. 關於我們
   - 公司簡介
   - 品牌理念
   - 發展歷程
   - 經營優勢
   - 品質承諾與服務標準
   - 企業責任或永續採購理念

3. 商品與品類
   - 商品分類，例如生活用品、食品飲料、服飾配件、居家選物、節慶禮盒
   - 每個分類要有簡短介紹與推薦理由
   - 主打商品卡片，包含商品名稱、特色、適合族群、價格或促銷文字
   - 新品、熱銷、限時優惠標籤

4. 服務與會員
   - 會員註冊與點數累積
   - 線上訂購與門市取貨
   - 退換貨政策摘要
   - 禮品卡、企業採購或團購服務
   - 客服支援與常見問題

5. 門市據點
   - 門市查詢區塊
   - 營業時間、地址、電話
   - 交通方式與停車資訊
   - 最新開幕或特色門市推薦

6. 最新消息或活動
   - 促銷活動
   - 品牌公告
   - 新品上市
   - 節慶檔期
   - 會員限定優惠

7. 聯絡我們
   - 聯絡表單
   - 客服電話與 Email
   - 合作洽談入口
   - 企業採購詢價
   - 社群連結

## 首頁文案方向

請讓首頁具備明確商業轉換目標。Hero 區塊可以使用以下方向：

- 標題：為每一天，挑選更好的生活
- 副標：從日常必需到風格選品，我們用穩定品質、合理價格與貼心服務，陪你完成每一次購物。
- 主要 CTA：探索商品
- 次要 CTA：查找門市

## 設計要求

- 以商品與優惠資訊為主，不要做成純形象頁
- 商品卡片要清楚可掃描
- 門市、會員、促銷活動要在首頁有明顯入口
- 頁尾需包含公司資訊、客服資訊、社群、隱私權政策、退換貨政策
- 預留電子商務功能區塊，例如購物車、會員登入、商品分類導覽
- 語氣要可靠、親切、有服務感
