# 3C 產業公司網站 Prompt

## SiteForge AI 產站 Prompt

請為一家「3C 產業公司」設計完整的商業網站。網站可適用於消費電子品牌、電腦周邊、智慧家電、手機配件、IoT 裝置、維修服務、系統整合或電子產品代理商。

網站要呈現科技感、可靠性、產品規格清楚、售後服務完整，並兼顧 B2C 商品銷售與 B2B 合作洽詢。整體設計要專業、現代、資訊層級清楚，不能只是科技風背景，要能讓使用者快速理解產品價值、比較規格、找到購買與維修支援入口。

## 必備網站內容

請產生一個完整公司網站，至少包含以下內容：

1. 首頁
   - 品牌名稱與定位，例如「讓智慧科技更可靠地進入日常」
   - 主視覺 hero 區塊，包含產品價值、主打系列、CTA
   - 熱門產品或解決方案
   - 核心技術優勢
   - 應用情境，例如居家、辦公、電競、商用、教育、零售
   - 售後服務、保固與維修入口
   - 客戶案例或通路合作

2. 關於我們
   - 公司簡介
   - 技術背景
   - 研發能力
   - 品質控管
   - 供應鏈與出貨能力
   - 品牌承諾與售後服務理念

3. 產品與解決方案
   - 產品分類，例如筆電周邊、手機配件、智慧家電、IoT 裝置、商用設備、維修零件
   - 每個產品需包含產品名稱、關鍵特色、規格摘要、適用情境、價格或詢價 CTA
   - 規格比較區塊
   - 新品、熱銷、商用推薦、保固標籤

4. 技術與服務
   - 系統整合
   - 企業採購
   - 安裝設定
   - 維修檢測
   - 保固註冊
   - 韌體或軟體更新
   - 常見問題與下載中心

5. 客戶案例
   - 企業導入案例
   - 通路合作案例
   - 教育或商用場景
   - 解決的問題、導入內容、成果指標

6. 支援中心或部落格
   - 產品教學
   - 規格選購指南
   - 常見問題
   - 維修保養知識
   - 韌體更新公告
   - 新品發表

7. 聯絡我們
   - 一般客服
   - 維修申請
   - 企業採購詢價
   - 經銷合作
   - 技術支援
   - 社群與官方通路

## 首頁文案方向

Hero 區塊可以使用以下方向：

- 標題：可靠科技，讓工作與生活更順手
- 副標：從消費電子產品到企業級解決方案，我們提供穩定規格、快速支援與可擴充的智慧科技服務。
- 主要 CTA：查看產品
- 次要 CTA：企業採購洽詢

## 設計要求

- 產品規格要清楚，不能只有行銷口號
- 需要有比較表、應用情境、售後支援、保固與維修入口
- CTA 要包含「查看規格」、「立即購買」、「企業詢價」、「申請維修」
- 視覺可以有科技感，但版面要清楚、可信任、易掃描
- 頁尾需包含公司資訊、客服、保固政策、維修流程、隱私權政策、社群連結
