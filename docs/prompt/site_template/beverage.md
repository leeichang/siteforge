# 酒水業公司網站 Prompt

## SiteForge AI 產站 Prompt

請為一家「酒水業公司」設計完整的商業網站。網站可適用於酒類品牌、精釀啤酒、葡萄酒代理、威士忌品牌、調酒飲品、無酒精飲品、高端飲料或餐飲通路供應商。

網站要具備成熟品牌感、產品質感與商業可信度。若涉及酒類，請加入負責任飲酒提醒與年齡限制提示。網站內容要同時服務一般消費者、餐飲通路、經銷合作與企業採購需求。

## 必備網站內容

請產生一個完整公司網站，至少包含以下內容：

1. 首頁
   - 品牌名稱與定位，例如「為餐桌與聚會打造更有記憶點的風味」
   - 主視覺 hero 區塊，包含品牌價值、主打產品、CTA
   - 產品系列展示
   - 風味特色或釀造/製程亮點
   - 熱銷商品、推薦搭配或新品上市
   - 餐飲通路、經銷或企業採購入口
   - 負責任飲酒提醒或年齡限制聲明

2. 關於品牌
   - 公司簡介
   - 品牌故事
   - 製程、產地或原料來源
   - 品質管理與保存條件
   - 品牌理念與風味哲學
   - 合作通路與市場定位

3. 產品系列
   - 產品分類，例如精釀啤酒、葡萄酒、烈酒、調酒基底、氣泡飲、無酒精飲品
   - 每個產品需包含品名、風味描述、容量、酒精濃度或成分、適飲溫度、搭餐建議
   - 商品卡片需包含產品亮點、適合場合、通路或詢價 CTA
   - 新品、限量、得獎、熱銷標籤

4. 通路與合作
   - 餐廳酒單合作
   - 經銷代理
   - 企業採購
   - 活動酒水供應
   - 婚宴、派對、品牌活動方案
   - 批發詢價表單

5. 品飲知識或部落格
   - 風味指南
   - 酒水搭餐
   - 調酒教學
   - 保存方式
   - 品牌活動紀錄
   - 新品發表文章

6. 活動與體驗
   - 品飲會
   - 快閃活動
   - 餐酒搭配晚宴
   - 品牌聯名
   - 門市或酒吧合作活動

7. 聯絡我們
   - 一般客服
   - 經銷合作
   - 餐飲通路洽談
   - 企業採購詢價
   - 活動合作
   - 社群與官方帳號

## 首頁文案方向

Hero 區塊可以使用以下方向：

- 標題：把每一次相聚，釀成更好的風味
- 副標：從精選原料到穩定供應，我們為餐飲通路、企業活動與日常品飲提供有質感的酒水選擇。
- 主要 CTA：探索產品系列
- 次要 CTA：洽詢通路合作

## 設計要求

- 若是酒類品牌，頁面需包含「請理性飲酒，未滿法定飲酒年齡請勿飲酒」等提醒
- 產品資訊要清楚呈現容量、風味、酒精濃度或成分、適飲情境
- CTA 要包含「查看產品」、「批發詢價」、「預約品飲」、「合作洽談」
- 視覺要有質感但不能只像形象海報，要有實際商業轉換資訊
- 頁尾需包含公司資訊、法規提醒、客服、合作洽詢、隱私權政策、社群
