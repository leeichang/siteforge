# 美妝業公司網站 Prompt

## SiteForge AI 產站 Prompt

請為一家「美妝保養品牌」設計完整的商業網站。網站要適合保養品、彩妝、香氛、美容儀器、沙龍保養或醫美周邊品牌使用。整體要有高級感、乾淨、精緻、可信任，能傳達品牌美學、產品功效與安全性。

網站必須同時兼顧品牌形象與商業轉換，讓使用者可以快速理解品牌定位、探索產品系列、查看成分與功效、閱讀使用教學、加入會員或預約諮詢。

## 必備網站內容

請產生一個完整公司網站，至少包含以下內容：

1. 首頁
   - 品牌名稱與核心主張，例如「以科學配方，打造穩定透亮肌」
   - 主視覺 hero 區塊，包含品牌價值、產品主打、CTA
   - 明星商品或新品系列
   - 主要功效分類，例如保濕、修護、亮白、抗老、舒敏、控油
   - 品牌成分理念或研發特色
   - 使用者評價、前後體驗或媒體推薦
   - 專業諮詢、肌膚測驗或預約服務入口

2. 關於品牌
   - 品牌故事
   - 創辦理念
   - 研發與品質管理
   - 配方安全承諾
   - 不動物實驗、環保包材或永續理念
   - 適合膚質與品牌差異化

3. 產品系列
   - 產品分類，例如潔顏、化妝水、精華、乳霜、防曬、彩妝、香氛
   - 每個系列需包含功效、適合膚質、使用情境
   - 商品卡片需包含產品名稱、關鍵成分、主打功效、容量、價格或 CTA
   - 明星商品、熱銷商品、新品上市標籤

4. 成分與功效
   - 核心成分介紹
   - 功效說明，例如玻尿酸保濕、胜肽修護、菸鹼醯胺提亮
   - 敏感肌注意事項
   - 使用順序與搭配建議
   - 安全測試或認證資訊

5. 美容顧問與服務
   - 線上肌膚測驗
   - 保養建議
   - 專人諮詢
   - 沙龍或櫃點預約
   - 會員專屬保養計畫

6. 美妝知識或部落格
   - 保養教學
   - 成分知識
   - 季節保養指南
   - 彩妝技巧
   - 常見肌膚問題解答

7. 聯絡我們
   - 客服表單
   - 產品諮詢
   - 批發或代理洽談
   - 實體櫃點資訊
   - 社群連結

## 首頁文案方向

Hero 區塊可以使用以下方向：

- 標題：讓肌膚回到穩定發光的日常
- 副標：以溫和配方、有效成分與透明資訊，為不同膚質打造可持續的美麗方案。
- 主要 CTA：探索明星商品
- 次要 CTA：開始肌膚測驗

## 設計要求

- 視覺要精緻，但不要只有大片空白與漂亮照片，必須有完整商業內容
- 產品資訊要清楚呈現成分、功效、適用膚質與使用方式
- CTA 要包含「立即選購」、「肌膚測驗」、「預約諮詢」、「查看成分」
- 頁尾需包含品牌資訊、客服、退換貨、隱私權、社群、櫃點
- 語氣要專業、溫柔、可信任，不要誇大療效
