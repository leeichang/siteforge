# 抽獎顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「掃碼抽獎結果顯示頁」。此頁面通常由使用者掃描商品 QR Code、活動碼、發票碼或會員活動入口後開啟。頁面需要顯示抽獎資格、抽獎結果、獎項資訊與領獎方式。

## 頁面目標

讓使用者清楚知道是否中獎、獎項是什麼、如何領獎，並引導使用者加入會員、分享活動或繼續參與品牌互動。

## 必備內容

1. 頁首
   - 活動品牌 Logo
   - 活動名稱
   - 活動期間
   - 活動規則入口

2. 抽獎結果主區塊
   - 狀態：恭喜中獎、未中獎、已抽過、資格不符、活動已結束
   - 結果時間
   - 抽獎序號或參加編號
   - 清楚的結果視覺

3. 獎項資訊
   - 獎項名稱
   - 獎項圖片
   - 獎項價值
   - 領獎期限
   - 兌換碼或核銷碼
   - 物流或門市領取方式

4. 參加者資訊
   - 會員登入狀態
   - 手機或 Email 後四碼
   - 是否已填寫領獎資料
   - 個資同意狀態

5. 行動按鈕
   - 填寫領獎資料
   - 儲存兌換碼
   - 查看活動規則
   - 分享活動
   - 加入會員
   - 聯絡客服

6. 活動規則摘要
   - 活動期間
   - 參加資格
   - 每人參加次數限制
   - 獎項配送或兌換方式
   - 注意事項

7. 頁尾
   - 主辦單位
   - 客服資訊
   - 隱私權政策
   - 活動條款

## 設計要求

- 第一屏要清楚顯示抽獎結果
- 中獎與未中獎狀態要有不同視覺，但都要維持品牌質感
- 領獎步驟要簡單明確
- 法規與活動條款入口要清楚
- 預留 API 資料欄位，例如 campaignName、drawStatus、prizeName、drawCode、drawnAt、claimDeadline、memberStatus
