# 追蹤追溯顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「產品追蹤追溯資訊顯示頁」。此頁面通常由消費者、通路商、稽核人員或企業客戶掃描產品 QR Code 後查看，用於呈現產品來源、批號、生產、檢驗、物流與銷售通路資訊。

## 頁面目標

讓使用者清楚理解產品從原料、生產、檢驗、物流到銷售的完整流向，提升透明度、信任感與合規能力。

## 必備內容

1. 頁首
   - 品牌 Logo
   - 追蹤追溯查詢標題
   - 產品或批號搜尋入口

2. 查詢結果主區塊
   - 查詢成功狀態
   - 產品名稱
   - 批號
   - 追溯碼
   - 查詢時間
   - 目前產品狀態，例如已出貨、已到店、已售出、已召回

3. 產品基本資訊
   - 品牌
   - 品名
   - 規格
   - 製造日期
   - 有效期限
   - 生產工廠
   - 產地或來源

4. 追溯時間軸
   - 原料來源
   - 生產製造
   - 品質檢驗
   - 包裝入庫
   - 物流配送
   - 通路上架
   - 消費者掃碼

5. 品質與檢驗資訊
   - 檢驗項目
   - 檢驗結果
   - 檢驗日期
   - 檢驗機構
   - 合格證明或報告下載

6. 物流與通路資訊
   - 出貨日期
   - 配送批次
   - 倉儲資訊
   - 經銷商或門市
   - 溫控或保存條件

7. 行動按鈕
   - 下載追溯報告
   - 聯絡品牌客服
   - 回報異常
   - 查看產品詳情

8. 頁尾
   - 公司資訊
   - 追溯資料聲明
   - 隱私權政策
   - 客服資訊

## 設計要求

- 資訊量較大，但必須層級清楚、可掃描
- 使用時間軸呈現追蹤追溯流程
- 重要狀態與檢驗結果要有清楚標籤
- 頁面要有官方可信任感，適合食品、酒水、美妝、藥妝、電子產品或高價商品
- 預留 API 資料欄位，例如 traceCode、batchNumber、productStatus、origin、factoryName、inspectionResult、logisticsStatus、scannedAt
