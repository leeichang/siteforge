# 掃碼顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「掃碼結果顯示頁」。此頁面由使用者掃描 QR Code、NFC、條碼或短網址後進入，可用於商品資訊、活動入口、會員互動、門市導流、售後服務或文件查看。

## 頁面目標

讓使用者掃碼後立即理解目前掃到的是什麼，並依情境完成下一步操作，例如查看商品、領取優惠、註冊會員、下載文件或聯絡客服。

## 必備內容

1. 頁首
   - 品牌 Logo
   - 掃碼結果標題
   - 語言切換或客服入口

2. 掃碼結果主區塊
   - 掃碼成功狀態
   - 掃碼時間
   - 掃碼類型，例如商品資訊、活動頁、保固登錄、文件下載
   - 來源代碼或 QR Code ID

3. 主要內容卡片
   - 商品或活動名稱
   - 簡短說明
   - 圖片或品牌視覺
   - 狀態標籤，例如有效、已過期、已使用、需登入

4. 可執行動作
   - 查看詳細資訊
   - 領取優惠
   - 加入會員
   - 登錄保固
   - 下載文件
   - 聯絡客服

5. 補充資訊
   - 使用說明
   - 活動規則摘要
   - 有效期限
   - 注意事項
   - 門市或通路資訊

6. 頁尾
   - 公司資訊
   - 客服
   - 隱私權政策
   - 使用條款

## 設計要求

- 手機優先，掃碼結果必須在第一屏清楚可見
- 頁面要能支援不同掃碼情境，不要設計得太單一
- 使用清楚的卡片式資訊層級
- CTA 必須根據掃碼目的明確呈現
- 預留 API 資料欄位，例如 qrCodeId、scanType、scannedAt、status、targetName、expireAt、ctaUrl
