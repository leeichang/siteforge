# SiteForge 樣板網頁 Prompt

這個資料夾存放「單一功能顯示頁」的 prompt，適合用在掃碼後的落地頁、產品驗證頁、會員互動頁、追蹤追溯頁與 DPP 數位產品護照頁。

- [掃碼顯示網頁](./scan_result_display.md)
- [抽獎顯示網頁](./lottery_display.md)
- [點數兌換顯示網頁](./points_redemption_display.md)
- [追蹤追溯顯示網頁](./traceability_display.md)
- [DPP 顯示網頁](./dpp_display.md)

## 使用建議

這類頁面通常由 QR Code、NFC、短網址、序號查詢或會員活動入口觸發，設計時請優先考慮手機瀏覽：

- 第一屏必須立即顯示主要結果或狀態。
- 重要狀態要有明確顏色與圖示，例如正品、異常、已兌換、已參加、追溯完成。
- 內容要可信任，包含品牌、產品、批號、時間、驗證碼、來源資訊。
- CTA 要明確，例如聯絡客服、查看產品資訊、加入會員、領取獎項、兌換點數、下載報告。
- 頁面需保留公司資訊、隱私權、客服與法規聲明位置。
