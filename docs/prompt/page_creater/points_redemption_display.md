# 點數兌換顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「會員點數兌換結果顯示頁」。此頁面用於會員掃碼、進入活動、兌換商品、兌換優惠券或查詢點數交易後顯示結果。

## 頁面目標

讓會員清楚知道目前點數餘額、兌換是否成功、兌換品項是什麼、如何使用兌換結果，並引導會員繼續累積點數或瀏覽更多兌換商品。

## 必備內容

1. 頁首
   - 品牌 Logo
   - 會員點數中心標題
   - 會員資料入口或登入狀態

2. 兌換結果主區塊
   - 狀態：兌換成功、點數不足、兌換失敗、已兌換、優惠已過期
   - 交易時間
   - 交易編號
   - 本次扣除點數
   - 目前剩餘點數

3. 兌換品項
   - 商品或優惠券名稱
   - 圖片
   - 所需點數
   - 有效期限
   - 使用方式
   - 兌換碼或條碼顯示區

4. 會員資訊
   - 會員等級
   - 點數餘額
   - 即將到期點數
   - 累積進度條
   - 下一級會員門檻

5. 行動按鈕
   - 使用兌換券
   - 儲存到手機
   - 查看我的兌換紀錄
   - 繼續兌換
   - 查看點數任務
   - 聯絡客服

6. 推薦兌換
   - 3 到 4 個推薦兌換品
   - 顯示所需點數、剩餘數量、有效期限

7. 頁尾
   - 點數規則
   - 客服資訊
   - 隱私權政策
   - 會員條款

## 設計要求

- 手機優先，點數餘額與兌換狀態要非常清楚
- 條碼或兌換碼區塊需可被門市人員快速掃描或辨識
- 點數交易資訊要可信任，避免模糊文案
- CTA 要清楚區分「立即使用」與「繼續瀏覽」
- 預留 API 資料欄位，例如 memberName、memberLevel、pointsBalance、pointsUsed、redeemStatus、voucherCode、expireAt、transactionId
