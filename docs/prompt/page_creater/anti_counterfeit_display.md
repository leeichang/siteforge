# 防偽顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「產品防偽驗證結果顯示頁」。此頁面通常由消費者掃描商品上的 QR Code、防偽標籤、NFC 或輸入序號後開啟。頁面必須讓使用者在第一眼就知道商品是否為正品、驗證是否成功、是否有異常風險。

## 頁面目標

讓消費者快速確認產品真偽，建立品牌信任，並在異常時引導使用者聯絡客服或回報疑似仿冒品。

## 必備內容

1. 頁首
   - 品牌 Logo
   - 產品防偽驗證標題
   - 客服或回首頁入口

2. 驗證結果主區塊
   - 明確狀態：正品驗證成功、驗證碼已被查詢、驗證失敗、疑似異常
   - 使用清楚的狀態顏色與圖示
   - 驗證時間
   - 驗證序號或防偽碼後四碼
   - 查詢次數提醒

3. 產品資訊
   - 產品名稱
   - 品牌名稱
   - 規格或容量
   - 批號
   - 製造日期或有效期限
   - 建議售價或銷售區域

4. 安全提醒
   - 若為首次驗證，顯示安心提示
   - 若已多次驗證，提醒可能有風險
   - 若驗證失敗，提醒不要使用並聯絡客服

5. 行動按鈕
   - 查看產品詳情
   - 聯絡客服
   - 回報疑似仿冒
   - 加入會員或登錄保固

6. 品牌信任資訊
   - 官方驗證聲明
   - 防偽技術簡介
   - 正品購買通路提醒
   - 客服資訊

7. 頁尾
   - 公司名稱
   - 客服電話與 Email
   - 隱私權政策
   - 使用條款

## 設計要求

- 以手機優先設計，第一屏直接顯示驗證結果
- 狀態卡片要非常清楚，不要讓使用者誤判
- 正品狀態使用安心、可信任的視覺；異常狀態使用警示但不要造成恐慌
- 頁面要像正式品牌官方驗證頁，不要像一般活動頁
- 預留 API 資料欄位，例如 productName、serialNumber、batchNumber、verifiedAt、verifyCount、status
