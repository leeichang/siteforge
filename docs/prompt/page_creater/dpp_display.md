# DPP 顯示網頁 Prompt

## SiteForge AI 單頁 Prompt

請設計一個「DPP 數位產品護照顯示頁」。DPP 是 Digital Product Passport，用於呈現產品身份、材料、製造、合規、永續、維修、回收與生命週期資訊。此頁面通常由 QR Code、NFC 或產品序號開啟。

## 頁面目標

讓消費者、品牌、通路商、維修商、回收商或監管單位快速查看產品的可信資料，理解產品來源、材料、合規狀態、碳足跡、維修資訊與回收方式。

## 必備內容

1. 頁首
   - 品牌 Logo
   - Digital Product Passport 標題
   - 語言切換
   - 資料更新時間

2. 產品身份主區塊
   - 產品名稱
   - 產品圖片
   - 型號
   - 序號或 DPP ID
   - 批號
   - 製造日期
   - 產品狀態，例如有效、已召回、停產、保固中

3. 產品摘要
   - 品牌
   - 類別
   - 主要用途
   - 產地
   - 製造商
   - 進口商或責任企業
   - 認證標章摘要

4. 材料與成分
   - 主要材料
   - 回收材料比例
   - 危害物質聲明
   - 包材資訊
   - 可拆解或可維修零件

5. 合規與認證
   - 法規符合狀態
   - 認證名稱
   - 檢測報告
   - 文件下載
   - 有效期限
   - 發證機構

6. 永續與碳資訊
   - 碳足跡摘要
   - 能源使用或效率等級
   - 水資源或環境影響
   - 回收比例
   - 永續承諾

7. 生命週期時間軸
   - 原料來源
   - 生產製造
   - 品質檢驗
   - 運輸配送
   - 銷售
   - 使用保養
   - 維修
   - 回收或再利用

8. 維修與保固
   - 保固狀態
   - 保固期限
   - 維修手冊
   - 零件資訊
   - 授權維修據點
   - 申請維修 CTA

9. 回收與再利用
   - 回收方式
   - 回收據點
   - 拆解指引
   - 二手流通或以舊換新資訊
   - 聯絡回收服務

10. 行動按鈕
   - 下載產品護照
   - 查看檢測文件
   - 申請維修
   - 查找回收據點
   - 聯絡品牌
   - 回報產品異常

11. 頁尾
   - 資料來源聲明
   - 公司資訊
   - 隱私權政策
   - 使用條款
   - 客服資訊

## 設計要求

- 手機與桌面都要易讀；DPP 資訊多，需使用清楚分區、標籤、摘要卡與時間軸
- 第一屏要顯示產品身份、狀態與資料更新時間
- 合規、永續、維修、回收資訊都要有明確入口
- 視覺要專業、可信任、偏資料儀表板，但仍保有品牌感
- 適合 3C、酒水、美妝、服飾、食品、電池、家電、精品等產業使用
- 預留 API 資料欄位，例如 dppId、productName、serialNumber、modelNumber、complianceStatus、carbonFootprint、warrantyStatus、repairManualUrl、recyclingInfo、updatedAt
