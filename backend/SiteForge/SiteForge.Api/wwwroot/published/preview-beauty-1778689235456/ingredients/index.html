敏弱肌膚特別建議

局部測試：首次使用新產品時，建議先在耳後或手腕內側小範圍塗抹，觀察 24 小時確保無任何不適反應。

漸進式適應：對於含有高濃度活性成分（如菸鹼醯胺）的產品，初期可每隔一日使用，待肌膚耐受度建立後再增加頻率。

鎮靜優先：若正處於過敏發作期，請先停用所有活性精華，僅使用 AETHERIS 純粹舒緩噴霧進行補水。
